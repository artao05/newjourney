### Three bugs found on `main` along the way

These are worth knowing for the pilot, even if you never merge this branch.

1. **The Route tab's action buttons were invisible.** MapLibre's stylesheet makes the
   map full height, which pushed the row below the clipped edge. The fix is in
   `14e8730`. It is a CSS and layout change that could be cherry-picked onto `main`.
2. **`npm test` exited 1 locally on every run.** CI passed, probably because a
   faster runner never hit the 60 s window. The fix is in `1c839fa`.
3. **Setup claimed mast height scaled the forecast**, and nothing used it. Corrected in
   `0b6a353`.
